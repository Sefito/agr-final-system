# Commercial interface

Status: review/approval interface proposed.

Show workflow status, missing-input questions, draft/edit proposals, version differences and explicit action buttons. Distinguish generated preview, approved proposal, committed document and published document.

Decisions: approval sends a stable proposal/version identity; disable accidental repeated submission while still handling safe retries; stale proposals show a conflict/review requirement; a chat reply is not an implicit authorization to save. Reconnect using authorized business status rather than replaying an old local assumption.

Acceptance: double-click causes one result; another user's edit triggers a clear conflict; failed response after successful save resolves to the committed version; revoked rights remove unavailable actions and protected data.

Open: review/diff presentation, task-list behavior and approved cross-user delegation. Advanced Office reconstruction is outside initial scope.
