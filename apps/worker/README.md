# Worker application

Status: job host selected; scheduler and durable execution open.

Execute document extraction/indexing, selected source synchronization and recoverable commercial computation through public package operations. Reuse the same business commands as the API. Do not import API routes or duplicate workflow rules.

The host owns execution startup, resource/concurrency limits, task ownership, cancellation and shutdown. Business proposals, versions and receipts remain package-owned. Work is driven by the selected job mechanism; no queue/engine is selected by this folder.

API/worker may share an image. Decide always-on versus scheduled execution from latency, workload and recovery needs. A pending approval is stored data, not a busy worker.
