# Design documentation

Status: initial documentation pass, not implementation evidence.

[architecture](architecture/README.md) explains ownership, use-case interactions and delivery order. [decisions](decisions/README.md) records selected boundaries, provisional choices and unresolved options.

Every repository folder has a README defining its local responsibility. The architecture index links the major areas. Keep local details with their owner; shared contracts belong in architecture/decision records and are linked rather than copied everywhere.

Documentation is in English; product text may be Spanish. Change decisions when evidence or customer intent changes, and identify the superseded choice. Avoid treating a proposed design as an implemented or validated guarantee.
