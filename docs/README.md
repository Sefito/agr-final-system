# Design documentation

[architecture](architecture/README.md) defines package/host ownership, dependency rules, task/release design and delivery order. [decisions](decisions/README.md) distinguishes retained, superseded, provisional and open choices.

Local READMEs define every folder. Shared architectural decisions are linked rather than independently reinvented. This is documentation-only design work; no real workspace targets, imports, tests or deployments have been verified.

[Requirements](requirements/README.md) define intended product behavior independently of packages/frameworks. Start with the functional draft for product scope, then use architecture documents for implementation responsibility.
