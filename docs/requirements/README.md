# Product requirements

[Functional requirements](functional-requirements.md) specify user capabilities, business rules, acceptance scenarios and unresolved product decisions for AGR Final System.

Status: draft for product/customer review. Confirmed scope and inherited invariants are distinguished from proposed behavior and optional capabilities. Package names, frameworks and cloud services do not define functional scope.

Requirements have stable IDs for later implementation/test traceability. Update this document when product scope changes; do not silently settle open behavior inside a package implementation.
